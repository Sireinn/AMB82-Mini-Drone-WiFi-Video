# 每周进度记录

A～E 每位成员每周提交一份进度，使用任务分支并通过 Pull Request 合并。

## 路径约定

docs/progress/YYYY-Www/A.md（其他成员使用 B.md、C.md、D.md、E.md）。例如 2026-W48/A.md。周次采用 ISO 周编号。

## 周报模板

复制以下内容到个人周报，填写实际情况：

```markdown
# 每周进度

- 成员：
- 负责模块：
- 周次与日期：

## 本周计划

## 已完成工作

## 实际成果
- 代码/文档路径：
- 关联 Issue / Pull Request / 提交：
- 原始日志、数据或截图路径：

## 测试结果
- 环境与版本：
- 方法与判定标准：
- 实际结果（未测则写未测）：

## 当前问题与需要协助

## 下周计划
```

不以提交次数替代成果质量；完成情况应链接到可检查的成果或测试证据。
