## 模块目标

根据实际飞控型号适配通信协议，实现报文生成、解析与测试工具。

## 环境与接口

- 飞控型号：Pixhawk 6C
- 固件：PX4，可通过心跳中的 autopilot 字段识别
- 协议：MAVLink 2，帧头 0xFD
- 连接方式：USB 口为 Type-C，可直接连电脑读取数据
- 串口：TELEM1/2/3 均已被占用，后续联调需协调；波特率待确认（PX4 TELEM1 默认 57600）
