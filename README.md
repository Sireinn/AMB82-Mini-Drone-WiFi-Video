# AMB82-Mini-Drone-WiFi-Video

基于 Realtek AMB82-Mini 的无人机 Wi-Fi 图传与飞控串口通信系统，大创项目代码、硬件资料、测试数据与阶段成果。

## 项目目标

- 实现机载摄像头采集、编码与 Wi-Fi 视频传输。
- 实现网络与飞控 UART 之间的数据转发及协议适配。
- 建立 Windows 地面端，用于视频显示、通信与日志记录。
- 保存接线文档、原始测试数据和阶段成果，支持集成与结题。

## 当前阶段

仓库初始化。功能实现、设备型号、接口参数与性能指标以各模块后续提交和测试记录为准，目前均待确认。

## 协作方式

1. 开始任务前同步 main，并新建任务分支，例如 feat/a-wifi-uart 或 docs/a-module-plan。
2. 在对应模块内提交代码与说明；提交信息写清具体变更。
3. 创建 Pull Request，说明修改内容、验证方法、结果与待解决问题。
4. 由仓库负责人或指定成员审核后合并到 main。
5. 每周更新个人进度，并链接实际代码、文档或测试证据。

上述审核流程是团队约定，是否启用分支保护由负责人另行配置。

## 首次参与

请先完善自己模块的 README：模块目标、开发环境、输入输出、当前问题及下一步计划；完成一次分支提交和 Pull Request。具体运行方法由模块负责人随可运行成果补充。

## 提交注意事项

- 不提交 Wi-Fi 密码、账号令牌、API Key 或其他敏感信息。
- 不提交编译缓存、Python 虚拟环境及无关安装包。
- 大型演示视频放在团队约定的存储位置，在 evidence 中保存链接与说明。
- 未经实际验证的功能和指标标明待验证，不写成已完成。
