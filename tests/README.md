# 测试记录与报告

协调负责人：E；各模块负责人提交本模块原始证据。

## 保存内容

- 测试计划与可复现步骤。
- 原始串口/网络日志、CSV 数据、测试报告。
- 系统联调记录与问题复现材料。

## 每次测试至少记录

1. 日期、执行人、关联任务和代码提交版本。
2. 硬件型号、软件版本、接线及网络环境。
3. 测试目的、操作步骤、判定标准。
4. 实际结果、原始文件路径及异常现象。
5. 结论与后续处理；未测试项明确标为待测。

## 命名建议

按日期与任务建立子目录，例如 YYYY-MM-DD_uart-loopback/；原始日志保留采集条件、单位与字段说明。视频等大型材料在 evidence 中记录存储链接。
